X Claude Code News Watch

One scheduled script replaces a manual daily scan of X for Claude Code news. xAI's Grok model, called with its x_search tool, finds the 5 most notable posts from the past 24 hours and writes a ready-to-read digest. The digest is delivered straight into an Evernote notebook by email — no server, no dashboard, and no Evernote API integration (new developer tokens have been unavailable since Evernote deprecated that program in favor of OAuth-only access).

Step 1

X Search & Summarize

research.mjs

Calls xAI's /v1/responses endpoint with the x_search tool enabled, instructing Grok to search X for Claude Code announcements, tips, and notable discussion from the last 24 hours, then narrow the results down to the 5 most valuable, non-duplicate items — each with a one-line summary, a link to the source post, and a note on why it matters.

Step 2

Deliver to Evernote

research.mjs

Emails the digest via Gmail SMTP to Evernote's note-import address. A @Notebook token in the subject line files the note directly into the right notebook — no Evernote API call required.
